# Demo Web Shop – UI-Testautomatisierung

Dieses Projekt enthält automatisierte UI-Tests für die Webanwendung Demo Web Shop.

Das Projekt demonstriert die Automatisierung typischer Benutzerszenarien mit Java, Selenium WebDriver und TestNG.

## Verwendete Technologien

- Java
- Selenium WebDriver
- TestNG
- Gradle
- WebDriverManager
- Git
- GitHub

## Automatisierte Tests

Das Projekt enthält automatisierte UI-Tests für verschiedene Funktionen, darunter:

- Überprüfung der Startseite
- Registrierung eines neuen Benutzers
- Positive Registrierungsszenarien
- Negative Registrierungsszenarien
- Login-Funktionalität
- Hinzufügen von Produkten zum Warenkorb

## Testansatz

Im Projekt werden unter anderem folgende Testansätze verwendet:

- Positive und negative Testszenarien
- Überprüfung von UI-Elementen
- Assertions zur Validierung der Testergebnisse
- Wiederverwendbare Hilfsmethoden
- Automatisierte Browserinteraktionen mit Selenium WebDriver

## Projektstruktur

- `src` – Java-Quellcode und automatisierte Tests
- `screenshots` – während der Tests erstellte Screenshots
- `build.gradle` – Gradle-Projektkonfiguration

## Tests ausführen

1. Repository klonen
2. Projekt in IntelliJ IDEA öffnen
3. Sicherstellen, dass Java installiert ist
4. Gradle die benötigten Abhängigkeiten herunterladen lassen
5. Tests mit TestNG ausführen

## Projektziel

Dieses Projekt wurde im Rahmen meiner Ausbildung im Bereich QA und Testautomatisierung erstellt und demonstriert praktische Kenntnisse in der UI-Testautomatisierung mit Java und Selenium WebDriver.
